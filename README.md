# Поиск вакансий на HeadHunter

Программа для поиска, фильтрации и сохранения вакансий с платформы HeadHunter.

## Установка

1. Убедитесь, что у вас установлен Python 3.8 или выше
2. Установите Poetry (если не установлен):
   ```bash
   pip install poetry

3. Клонируйте репозиторий

4. Установите зависимости:

  ```bash
   poetry install
```

## Использование
Запустите программу:

``` bash
poetry run python main.py
```

Следуйте инструкциям в консоли:

Введите поисковый запрос (например: Python)

Введите количество вакансий для вывода

Введите ключевые слова для фильтрации (через пробел)

Введите диапазон зарплат (например: 100000-150000)

Программа сохранит найденные вакансии в файл data/vacancies.json.

Тестирование
Для запуска тестов выполните:

```bash
poetry run pytest
```

### Структура проекта

src/api/ - модуль для работы с API

src/models/ - модели данных

src/storage/ - модуль для работы с хранилищем

src/utils/ - вспомогательные функции

tests/ - тесты

data/ - данные вакансий

main.py - точка входа
